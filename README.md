# Fashion Catalog

Sistema web de catálogo e gerenciamento de produtos, desenvolvido como projeto de aprendizado e aplicação prática de desenvolvimento web.

## Objetivo

Desenvolver uma aplicação que permita apresentar produtos ao público e gerenciar seu cadastro por meio de uma área administrativa.

## Tecnologias

- PHP
- Laravel
- PostgreSQL
- HTML
- CSS
- JavaScript

## Funcionalidades planejadas

### Catálogo público
- [ ] Página inicial
- [ ] Listagem de produtos
- [ ] Pesquisa e filtros
- [ ] Visualização de detalhes dos produtos

### Área administrativa
- [ ] Autenticação de usuários
- [ ] Cadastro de produtos
- [ ] Edição de produtos
- [ ] Exclusão de produtos
- [ ] Gerenciamento de categorias
- [ ] Upload de imagens

## Desenvolvimento

O projeto está em desenvolvimento. As funcionalidades serão implementadas gradualmente, com atenção à organização do código, validação de dados, segurança e relacionamento com o banco de dados.

## Instalação

As instruções de instalação e execução serão adicionadas conforme o desenvolvimento avançar.
